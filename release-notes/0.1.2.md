## 通用
- 新增“检查新版本”：有新版本时，设置的“关于”导航会出现一个提示点，设置窗口顶部也会提示一行“发现新版本”。
- 设置的“关于”页可以看到新版本的更新说明，并一键更新；更新只在你点“立即更新”之后才会进行，你的设置和历史都会保留。
- 可以在“关于”页关闭自动检查，也可以随时点“立即检查”。检查只会从 GitHub 读取一个很小的版本文件，不会上传任何数据。
- 托盘菜单有新版本时会多一项“有新版本”，点一下就能打开“关于”页。
- “关于”页加上了源代码（GitHub）和作者的 X 链接。

## Windows
- 发现新版本时会弹出一条系统通知，可以直接“查看更新”或“忽略此版本”。

## macOS
- 改用固定的签名证书。从 0.1.1 升到这个版本后，需要在“系统设置 → 隐私与安全性 → 辅助功能”里重新允许一次拈来；以后再更新就不用重新授权了。
